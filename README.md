# Gastro Chef
## Предварительная идея:
Учебный демо-проект курса веб-программирования. Проект будет развиваться поэтапно вместе с лекциями и практическими работами: от базовой HTML-структуры до полноценного интерфейса сервиса питания.
## Планируемый стек: 
HTML, CSS, JavaScript, PHP, MySQL.
## Запуск:
Инструкция по запуску будет дополняться по мере разработки проекта.
